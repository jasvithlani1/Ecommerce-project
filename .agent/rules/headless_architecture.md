# Headless Architecture via WPGraphQL

- **Framework**: Next.js
- **CMS**: WordPress (Headless)
- **Plugin**: WPGraphQL
- **Data Fetching**: All data fetching must be done via GraphQL queries to the WPGraphQL endpoint.
- **Components**: UI components should be decoupled from the backend and use the data provided by the GraphQL queries.
- **Types**: Use TypeScript for all components and data fetching.
